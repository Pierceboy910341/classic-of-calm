# 06 Suno 主打曲（每週 5 首）

從 2026-11-15 起，每週合輯裡最好聽的 **5 首主打曲**由你在 **Suno**（一個 AI 作曲網站）上做；其他的歌還是由 Kaggle 免費自動生成。
Suno 沒有讓程式自動操作的方法，所以這 5 首要你在網頁上按。Claude 每週會給你一張「複製貼上單」（`weekly/<週次>/suno.md`），照著貼就好。

> 小提醒：畫面上的英文按鈕寫成「英文」（中文意思）。Suno 常改版，按鈕位置可能不同；找不到就截圖給 Claude。

---

## 第 1 部分：訂閱 Pro 方案（只做一次）

1. 打開 **https://suno.com**，右上角 **Sign up**（註冊）。可以用 Google 帳號登入。
2. 左下角或右上角找 **Upgrade**（升級）／**Subscribe**（訂閱）。
3. 選 **Pro**，付款週期選 **Monthly**（每月，約 US$10）。⚠️ 不要選年繳，先用月繳。
4. 填信用卡 → 確認。
5. 完成後跟 Claude 說「**Suno 訂閱好了**」，並告訴它**今天幾號**（下載額度從這天起算一個月）。

**一定要知道的 3 件事**
- **只有「訂閱 Pro 的期間」做出來、下載的歌，才可以放在 YouTube 賺錢。** 取消訂閱之後做的歌不能用。所以不要隨便停掉訂閱；要停之前先問 Claude。
- **每個月 20 次下載**，**按一次 Download（下載）就算一次**。在網頁上**試聽是免費的**，不算次數。
- **沒用完的次數不會留到下個月。** 每週用 5 次，4 週剛好 20 次。

---

## 第 2 部分：每週做 5 首（大約 30–40 分鐘）

打開 Claude 給你的 `suno.md`（Claude 也會在對話裡貼給你）。每一首都照這 6 步：

1. suno.com → 左邊 **Create**（建立）→ 上方選 **Advanced**（進階；有些版本叫 Custom）。版本選最新的（v5.5 或 v6）。
2. **Lyrics**（歌詞）欄：**留空**，什麼都不要打。如果有 **Instrumental**（純音樂）開關，打開它。
3. **Styles**（風格）欄：貼上單子上的「Styles」。
4. 打開 **More Options**（更多選項）：有 **Exclude styles**（排除風格）就貼上「Exclude」；沒有就跳過。
5. **Song Title**（歌名）欄：貼上單子上的「歌名」。⚠️ **歌名一字不差**，Kaggle 是靠歌名認出哪個檔案是哪一首。
6. 按 **Create**（建立）。

**挑歌（最重要）**
- 每首**生成 2–3 次**，在網頁上**試聽**（免費），**只下載最好的 1 個**。
- 不要選：有人聲（唱歌、說話、「啊～」的合唱）、結尾突然斷掉、聽起來像日本音樂、中間有怪聲。
- 下載：在那首歌旁邊按 **⋯** → **Download**（下載）→ 選 **WAV Audio**（音質較好）；沒有 WAV 就選 **MP3 Audio**。**每首只下載一次。**
- 檔名**不用改**。

---

## 第 3 部分：記下用了幾次下載

每次 Claude 的 `suno.md` 開頭會寫「本月下載額度：還剩 X / 20 次」。你只要在對話裡告訴 Claude 實際下載了幾次（例如「這週下載了 6 次」），它會幫你記。

- 某一首做了 3 次都不滿意：先不要下載，跟 Claude 說「第 X 首不好」，它會改 Styles 給你。
- 這個月次數用完了：跟 Claude 說，這週改用 Kaggle 生成的歌補上（不用多花錢）。

---

## 第 4 部分：把 5 個檔案上傳到 Kaggle

Kaggle 的「02 Assemble」會從你的私人資料夾（Kaggle 叫 **Dataset**，資料集）拿這 5 首。

**第一次（只做一次）**
1. 打開 **https://www.kaggle.com** 並登入。
2. 左上角 **Create**（建立）→ **New Dataset**（新資料集）。
3. 把 5 個下載好的檔案**拖進去**。
4. **Title**（名稱）打：`classic-of-calm-suno`（一個字都不要改）。
5. 公開設定選 **Private**（私人）。⚠️ 一定要私人，不要公開別人就能下載。
6. 按 **Create**（建立）。等它顯示完成。
7. 打開「**02 Assemble**」筆記本 → 右側 **Add Input**（加入資料）→ **Datasets** → **Your Datasets**（你的資料集）→ 選 `classic-of-calm-suno` → **Add**（加入）。

**之後每週**
1. kaggle.com → 左邊 **Datasets** → **Your Work**（你的作品）→ 點 `classic-of-calm-suno`。
2. 右上角 **New Version**（新版本）。
3. 把這週的 5 個檔案拖進去（上週的檔案留著沒關係，系統會用歌名分辨）→ **Create**（建立）。
4. 跑「02 Assemble」之前：打開筆記本 → 右側 **Input**（輸入）→ 如果 `classic-of-calm-suno` 旁邊有「更新」（Update 或 ⟳）的提示，**按一下更新**。
5. 回 Claude 說「**Suno 上傳好了**」。Claude 會先抓下來檢查一次。

## 卡住了

| 狀況 | 怎麼辦 |
|---|---|
| 找不到 Exclude styles | 沒關係，跳過那一欄。 |
| 生成的歌有人聲 | 不要下載，再生成一次；三次都有就告訴 Claude。 |
| 不小心多下載了 | 沒關係，告訴 Claude 這週用了幾次。 |
| 02 Assemble 說「找不到任何 Suno 主打曲」 | 多半是第 4 部分第 4 步沒按更新，或第一次的第 7 步沒加入。截圖給 Claude。 |
| 上傳時檔名改不了／名字很怪 | 不用管檔名，只要 Suno 上的歌名照單子打就行。 |

## 還沒親自確認的地方（給 Claude 看的）
撰寫時（2026-11-15）無法登入 Suno／Kaggle 實際操作：
- Suno v5.5／v6 網頁版的按鈕名稱（Advanced／Custom、More Options、Exclude styles、Download 選單）與 Pro 價格。
- 下載檔裡是否一定寫入歌名（ID3 標題）；配對程式也會看檔名，兩者都沒有時會依檔名順序配對。
- Kaggle Notebook 加入的 Dataset 是否會自動用最新版本（目前請擁有者手動按更新）。
- Kaggle New Version 預設是否保留舊檔（保留也沒關係）。
